# Ping 宣传片 V2 动效脚本

继承已确认的“闺蜜约好周六下午 3 点喝咖啡”故事、产品事实与 CTA。主制作规范为 remotion-marketing-video。marketing-brief 和 video-script 作为上游策划参考；原 remotion-video 不参与本轮制作主导。

规格：30 秒，1080×1920，30fps，900 帧。加入本地原创轻音乐与短 UI 音，无配音。

| 时间 | 画面 | 文案 | 声音 |
| --- | --- | --- | --- |
| 0–3s | 同一设备中，闺蜜的咖啡约定先出现，再出现“好呀！”回复。镜头缓缓靠近对话 | 聊好了，怕忘了？ | 消息短音、轻音乐渐入 |
| 3–6s | 长按原句，弹出复制菜单，复制后设备持续存在，交叉溶解进入真实 Ping 首页 | 聊天里的约定，交给 Ping。 | 复制声、轻移动声 |
| 6–10s | 点击“使用剪贴板”，真实预览出现，镜头连续推进；点击“使用此内容”后 4 帧开始显示填入结果 | 复制的话，直接用。 | 两次点击 |
| 10–13s | 同一截图中的输入原句与 Ping 图标成为焦点，点击后 4 帧开始进入真实确认页 | 原句填好，Ping 一下。 | 点击、轻移动声 |
| 13–17s | 真实确认页放大，事项与时间保持稳定，强调线渐入并退场 | 事项、时间，核对一下。 | 音乐留出空间 |
| 17–21s | 镜头下移到确认按钮。点击后显示真实“正在保存”截图，编辑层说明授权条件。没有伪造已授权状态 | 确认提醒，记下这次约定。接收提醒，需要允许微信订阅消息。 | 点击 |
| 21–25s | “周六 15:00”明确时间跳转；同一约定在标注为演示的服务通知中出现 | 到了约定时间，咖啡局别忘了。 | 原创 Ping 短提示音 |
| 25–30s | 设备收拢退场，现有品牌字标、约定小记页和 CTA 分层进入 | 把想记住的事，轻轻 Ping 一下。打开 Ping，记下下一件事。 | 轻柔收束、渐出 |

实现时间源：remotion/src/promo/sceneGraph.ts。所有 startFrame 从 durationInFrames 累计得到；点击、结果和音效都引用同一 events 表。镜头路径与点击环共用 source-space 坐标，避免放大时错位。

真实截图只改变显示裁切、比例、位置和透明度。拍摄时已有系统提示条，用取景避开，不以修图删除内容。聊天和通知是明确标注的演示，提醒事项与时间匹配真实规则解析和云端解析结果。不增加聊天自动读取、自动粘贴、重复提醒或模型能力。

新增音乐与音效由 remotion/tools/generate-audio.py 本地生成，无下载样本；溯源在 remotion/public/audio/provenance.json。

拟最终输出：marketing/ping-chat-reminder/video.mp4。完整渲染须由用户批准 V2 预览并确认该输出路径后执行。
